01 / OVERVIEW
项目概述
核心价值

统一申请入口

标准化表单提交服务申请，11种服务类型覆盖，信息完整、格式统一

安全保障

身份二次验证

上传营业执照 + 留存联系方式，经服务商确认后通知售后处理

自动化

RFC 邮件线程识别

通过 RFC 5322 协议识别代理商确认邮件

  • - 解析 Message-ID / In-Reply-To
  • - References 重建邮件线程树
  • - 自动匹配代理商回复邮件
  • - 关联申请记录，更新验证状态
RFC 识别流程：发送邮件时记录 Message-ID -> IMAP 监听收件箱 -> 解析 In-Reply-To/References 匹配原邮件 -> 提取正文关键词（确认/拒绝）-> 更新申请验证状态 -> 通知售后
