客户服务申请系统 - 功能现状总览

V1.0 · 2026年7月31日 · 系统当前实现情况与数据收集规范
01 / FEATURES
已实现功能
表单

三步表单向导

选择服务类型 → 填写申请信息 → 身份验证 → 确认提交

校验

客户域名白名单校验

独立"客户域名"字段，与客户名单精确匹配 + 白名单兜底，未通过禁止提交

后台

许可域名管理后台

/admin/customers 管理页面：许可域名列表（域名/公司名/联系人/状态）、新增/编辑/停用、搜索筛选，支持后续 CSV 批量导入

条件

企业/个人用户区分

重置密码时选择用户类型，动态显示公司名称/营业执照（企业）或身份证（个人）

模板

申请表模板下载

9 种申请书模板 + 免责声明模板，解绑类支持多模板选择，下载后填写盖章上传

邮件

真实 SMTP 邮件转发

QQ 邮箱 SMTP 发送，营业执照/身份证/申请书/免责声明作为附件完整转发

识别

RFC 邮件线程识别

IMAP 每30秒轮询，通过 Message-ID / 主题申请编号匹配服务商回复，关键词判断确认/拒绝

存储

MySQL 数据持久化

applications 表 30+ 字段独立存储 + email_logs 邮件日志表 + customers 客户名单表

文件

附件本地存储

营业执照/身份证/申请书/免责声明保存至 uploads/ 目录，支持后台下载

后台

管理后台

申请列表（筛选/搜索/分页/自动刷新）+ 详情（完整度检查/邮件日志/状态管理）+ 客户名单 + 白名单管理

03 / STORAGE
数据存储结构
applications 表

申请主表（40+ 字段）

基础：id / submit_id / service_type / service_name / company_name / status / verify_status
联系人：applicant_name / applicant_email
业务字段：customer_type / receive_email / rss_confirmed / old_name / new_name / expiry_date / extend_date / extend_reason / unbind_reason
JSON 数组：sub_domains / alias_domains / unbind_devices
冗余备份：form_data (JSON) / verify_data (JSON)
附件路径：business_license_path / identity_card_path / application_form_path / disclaimer_path

辅助表

email_logs / customers / system_settings

email_logs：每次邮件发送记录（收件人类型/邮箱/主题/状态/Message-ID/错误信息）
customers：许可域名名单（域名/公司名/联系人/状态/启用停用），后台 /admin/customers 管理，支持 CSV 批量导入
system_settings：系统配置（白名单域名列表），后台 /admin/whitelist 管理
