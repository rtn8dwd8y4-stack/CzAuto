客户服务申请系统 - 部署架构图

    subgraph PUBLIC["🌐 公网区（零敏感数据）"]
        direction TB
        U["👤 用户浏览器
填写表单 · 上传附件"]
        FE["🖥️ 前端应用（无状态）
• 表单收集与本地校验
• 组装标准邮件格式
• SMTP 发送中转邮箱
• 提交即清空 · 零存储"]
        U --> FE
    end

    subgraph MBX["📮 中转邮箱（公司企邮专用账号）"]
        direction TB
        MB["中转邮箱
公司企邮专用账号
🔑 仅客户端专用密码
🚫 禁用网页登录
仅系统自动收发"]
        AG["📧 代理商邮箱"]
    end

    subgraph INTRA["🔒 隔离内网（不对外暴露）"]
        direction TB
        IM["② 邮件拉取与解析
IMAP :993 轮询中转邮箱
按标准格式解析字段
提取附件（申请书/免责声明等）"]
        DB1["③ 申请入库
创建申请记录（pending）
原始邮件归档 · 状态可追踪"]
        VAL["④ 域名与代理商校验
域名 → 客户库匹配
客户 → 代理商匹配
匹配失败走兜底邮箱"]
        FWD["⑤ 转发至代理商
生成 RHF-编号唯一标识
携带申请表附件
SMTP 发送验证邮件"]
        THR["⑥ 回复线程关联
Message-ID 精确匹配
RHF-编号/主题匹配
时间戳兜底"]
        ASM["⑦ 完整业务信息组装
原始请求 + 代理商确认
解析确认/拒绝关键词
附全部附件"]
        SUPPORT["⑧ 客服通知
确认 → 转发售后邮箱
拒绝 → 通知客户"]
        MYSQL[("MySQL
客户/代理商/申请记录
仅内网访问")]
        ADMIN["🛠️ 管理后台
申请查询 · 名单维护
仅内网访问"]

        IM --> DB1 --> VAL --> FWD --> THR --> ASM --> SUPPORT
        DB1 -.-> MYSQL
        VAL -.-> MYSQL
        THR -.-> MYSQL
        ADMIN -. "查询/配置" .-> VAL
        ADMIN -.-> MYSQL
    end

    FE --"① 标准邮件 SMTP:465"--> MB
    MB --"② 拉取 IMAP:993"--> IM
    FWD --"⑤ 验证邮件 SMTP"--> AG
    AG --"回复 确认/拒绝"--> MB
    MB --"⑥ 监控回件 IMAP:993"--> THR
实线 ─▶ 邮件流转（SMTP / IMAP 通信）   |   虚线 ┄▶ 数据库读写与后台管理访问（仅内网）
